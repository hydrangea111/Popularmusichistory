PLATE I

아메리카

미국 대중음악

0. 뿌리: 아프리카계 미국 뿌리음악 (19세기 이전~1900년대 초)

미국 대중음악의 거의 모든 갈래가 여기서 갈라져 나옴.

  • 필드 헐러 (Field Holler) — 노예 노동요, 콜 앤 리스폰스 구조. 블루스의 직접적 선조.
  • 링 샤웃 (Ring Shout) — 서아프리카 종교 의례가 기독교와 결합된 형태. 가스펠의 원형.
  • 니그로 스피리추얼 (Negro Spiritual) — 종교적 가사 + 콜 앤 리스폰스. → 가스펠, 블루스 양쪽에 영향.
  • 미국 앵글로-켈틱 발라드 전통 — 애팔래치아 지역 백인 이민자 민요. → 올드타임/컨트리 계열의 또 다른 뿌리.

이 두 축(아프리카계 리듬·보컬 전통 / 앵글로-켈틱 발라드 전통)이 미국 대중음악 전체를 관통하는 이중나선이라고 보면 이해가 쉬움.

1. 블루스 계열

필드 헐러 + 스피리추얼
        │
    블루스 (1890s~1900s, 델타 지역)
        │
        ├─ 델타 블루스 (Robert Johnson, Son House) — 미시시피
        │       │
        │       └─ 시카고 블루스 (Muddy Waters, 1940s~) — 전자화, 대이동(Great Migration)의 산물
        │               │
        │               ├─ 브리티시 블루스 붐 (1960s, John Mayall, 초기 Rolling Stones)
        │               │       └─ 하드록/헤비메탈로 분기 (아래 5번 참조)
        │               └─ 일렉트릭 블루스 → 소울/R&B에 화성적 영향
        │
        ├─ 피드몬트 블루스 — 랙타임식 핑거피킹, 동남부
        └─ 컨트리 블루스 → 초기 컨트리 뮤직에 유입 (Jimmie Rodgers 등)

2. 재즈 계열 (가장 복잡하게 분화)

랙타임 (Scott Joplin, 1890s~1910s) — 아프리카 리듬 + 유럽 클래식 화성/피아노
        │
    뉴올리언스 재즈 (Dixieland, 1900s~1920s) — 브라스밴드 + 블루스 + 랙타임
        │
        ├─ 시카고 스타일 재즈 (1920s)
        ├─ 스트라이드 피아노 (Harlem, James P. Johnson)
        │
    스윙/빅밴드 재즈 (1930s~40s, Duke Ellington, Count Basie)
        │
        ├─ 비밥 (Bebop, 1940s, Charlie Parker, Dizzy Gillespie) — 빠른 템포, 복잡한 화성, 춤곡에서 감상용으로 전환
        │       │
        │       ├─ 쿨 재즈 (Cool Jazz, Miles Davis 초기, 1950s) — 서부 해안, 느슨한 텐션
        │       ├─ 하드 밥 (Hard Bop, 1950s) — 블루스/가스펠 요소 재도입
        │       │       └─ 소울 재즈 (Soul Jazz) → 훵크에 영향
        │       ├─ 모달 재즈 (Modal Jazz, Kind of Blue, 1959) — 코드 진행 대신 선법 중심
        │       └─ 프리 재즈 (Free Jazz, Ornette Coleman, 1960s) — 조성/형식 해체
        │
        └─ 퓨전/재즈 록 (Jazz Fusion, 1970s, Miles Davis 전기, Weather Report)
                └─ 스무스 재즈 (1980s~, 상업화된 후계)

* 재즈 화성(ii-V-I, 텐션, 세컨더리 도미넌트)이 이후 R&B, 소울, 시티팝, 네오소울까지 관통하는 핵심 축.

3. 가스펠 → 컨트리 계열

니그로 스피리추얼 + 백인 셰이프노트 찬송가
        │
    가스펠 (1930s~, Thomas Dorsey) — 흑인 교회음악, 이후 소울 보컬 창법의 원천

앵글로-켈틱 발라드 + 스코틀랜드/아일랜드 무용곡
        │
    올드타임 뮤직 (Appalachia, 1920s 이전)
        │
    컨트리 뮤직 (1920s~, Jimmie Rodgers, Carter Family)
        │
        ├─ 블루그래스 (Bill Monroe, 1940s) — 어쿠스틱 현악, 빠른 템포
        ├─ 웨스턴 스윙 (Bob Wills) — 재즈 화성 + 컨트리
        ├─ 혼키통크 (Honky Tonk, 1940s~50s) — 술집 문화, 페달스틸
        │       └─ 낭빌 사운드 (Nashville Sound, 1950s~60s) — 스트링 섹션 도입, 팝화
        │               └─ 컨트리 팝 (1970s~)
        ├─ 아웃로 컨트리 (Outlaw Country, 1970s, Willie Nelson, Waylon Jennings)
        └─ 얼터너티브 컨트리/아메리카나 (1990s~) — 인디 록과 접점

4. 도둡/R&B → 록앤롤 → 소울/훵크/디스코 계열

블루스 + 가스펠 + 재즈 빅밴드의 소편성화
        │
    리듬 앤 블루스 (R&B, 1940s 후반) — 도시화된 흑인 대중음악, 재즈 빅밴드의 축소판(Jump Blues)
        │
        ├─ 두웝 (Doo-wop, 1950s) — 아카펠라 보컬 그룹
        │
        ├─ 로큰롤 (Rock and Roll, 1950s, Chuck Berry, Little Richard)
        │       └─ 로커빌리 (Rockabilly) — 컨트리 + R&B (Elvis Presley)
        │               └─ 브리티시 인베이전 (1960s, Beatles 초기) → 이후 록 계열로 역수입
        │
        ├─ 소울 (Soul, 1960s) — 가스펠 창법 + R&B
        │       ├─ 모타운 사운드 (Detroit) — 팝 친화적, 스트링/브라스 편곡
        │       ├─ 서던 소울 (Stax, Memphis) — 거칠고 그루브 중심
        │       └─ 스무스 소울/필리 소울 (1970s) → 디스코의 직접 선조
        │
        ├─ 훵크 (Funk, 1960s 말, James Brown) — 리듬 강조, "the one" 강박
        │       │
        │       ├─ P-Funk (Parliament-Funkadelic) — 사이키델릭 요소 결합
        │       └─ 디스코 (Disco, 1970s) — 훵크 + 필리 소울 + 4온더플로어 비트
        │               │
        │               ├─ 유로디스코 (해외로 확산)
        │               └─ 시카고 하우스로 직접 계승 (8번 참조)
        │
        └─ 콰이엇 스톰/어덜트 컨템포러리 R&B (1970s~80s)
                └─ 뉴 잭 스윙 (1980s 말, Teddy Riley) — 힙합 비트 + R&B 보컬
                        └─ 컨템포러리 R&B (1990s~) / 네오소울 (D'Angelo, Erykah Badu) — 재즈·소울 화성 재도입

5. 록 계열 (로큰롤 이후 분화)

로큰롤 + 브리티시 인베이전
        │
    개러지 록 (1960s 미국) 
        │
        ├─ 사이키델릭 록 (1960s 말, 지미 헨드릭스, 도어스)
        │       │
        │       ├─ 하드 록 (Led Zeppelin류, 블루스록에서 분화)
        │       │       └─ 헤비 메탈 (1970s, Black Sabbath) 
        │       │               └─ 서브장르 폭발: 스래시/데스/블랙/둠 메탈 등 (1980s~)
        │       │
        │       └─ 프로그레시브 록 (King Crimson, Yes) — 클래식/재즈 구조 차용
        │
        ├─ 글램 록 (David Bowie, 1970s)
        │
        ├─ 펑크 록 (Punk, 1970s 중반, Ramones, Sex Pistols) — 반문명적 반동, 단순화
        │       │
        │       ├─ 포스트펑크 (1970s 말~80s) — 실험적, 어두운 질감
        │       │       └─ 뉴웨이브 (New Wave, 1980s) — 신스 도입, 팝 친화적
        │       │               └─ 신스팝 (Depeche Mode류) → 일렉트로닉과 교차
        │       │
        │       ├─ 하드코어 펑크 (1980s, 미국 서부 해안)
        │       │       └─ 그런지 (Grunge, 1990s, 시애틀) — 펑크 + 헤비메탈 정서
        │       │               └─ 얼터너티브 록 (1990s~)
        │       │
        │       └─ 팝 펑크/이모 (1990s~2000s)
        │
        └─ 인디 록 (1980s~, 자체 레이블 문화) — 이후 모든 서브장르의 우산 개념화

6. 힙합 계열

자메이카 사운드 시스템 문화(토스팅) + 훵크/디스코 브레이크비트
        │
    힙합 (Hip Hop, 1970s 중반, 뉴욕 브롱크스)
        │
        ├─ 올드스쿨 힙합 (1970s 말~80s 초, Sugarhill Gang, Grandmaster Flash)
        │
        ├─ 골든 에이지 힙합 (1980s 말~90s 중반) — 샘플링 예술의 정점
        │       │
        │       ├─ 이스트 코스트 힙합 (뉴욕, 재즈 샘플링 중심, Nas, Wu-Tang)
        │       └─ 웨스트 코스트 힙합 (LA, 훵크 샘플링 중심)
        │               └─ 갱스타 랩 (N.W.A, Dr. Dre) — G-funk 사운드
        │
        ├─ 서던 힙합 (1990s~2000s, 애틀랜타/휴스턴) — 베이스 중심
        │       └─ 트랩 (Trap, 2000s~) — 808 베이스, 하이햇 롤
        │               └─ 2010년대 이후 전 세계 팝/힙합의 표준 리듬어법이 됨
        │
        └─ 컨셔스 힙합/얼터너티브 힙합 (De La Soul, A Tribe Called Quest 등) — 재즈 화성 재도입, 네오소울과 접점

7. 일렉트로닉 계열

디스코 (4온더플로어 + 신시사이저)
        │
    시카고 하우스 (House, 1980s 초, Frankie Knuckles) — 디스코의 DJ 리믹스 문화에서 발전
        │
        ├─ 디트로이트 테크노 (Techno, 1980s 중반, Juan Atkins) — Kraftwerk의 미국적 재해석
        │       └─ 유럽으로 역수출 → 레이브 문화, 이후 EDM 전반의 뿌리
        │
        ├─ 애시드 하우스 (1980s 말)
        │
        └─ 뉴욕 개러지 하우스 → R&B와 결합 → 2000년대 팝/R&B 프로덕션에 영향

8. 교차 요약: 핵심 흐름 5갈래

  1. 블루스 → 재즈/컨트리/록: 화성적 뼈대 제공
  2. 가스펠 → 소울 → 훵크/디스코 → 하우스: 보컬 창법과 그루브의 계보
  3. 로큰롤 → 록 서브장르 폭발: 백인 청년 문화 중심 분화
  4. 훵크/디스코 → 힙합: 브레이크비트 샘플링 문화
  5. 재즈 화성(ii-V-I, 텐션): 소울/네오소울/시티팝 등 화성 중심 장르에 계속 재유입되는 공통 언어

참고: 계보는 실제로는 이렇게 선형적이지 않고 상호 교차·역류가 훨씬 많음(예: 브리티시 블루스 붐이 미국 록에 역수입, 유로디스코가 다시 미국 하우스에 영향 등).

PLATE II

유럽

유럽 대중음악

0. 뿌리: 유럽 민속음악 전통

미국이 아프리카계/앵글로-켈틱 이중나선이라면, 유럽은 지역별 민속음악이 훨씬 파편적으로 남아있다가 20세기에 각각 다른 경로로 대중음악화됨.

  • 켈트 민속음악 (아일랜드/스코틀랜드) — 지그·릴 리듬, 모달 스케일 → 포크 리바이벌의 핵심 원천
  • 발칸/로마(집시) 브라스 전통 — 홀수박자, 브라스밴드 편성 → 발칸 브라스, 이후 일부 재즈/월드뮤직에 흡수
  • 플라멩코 (스페인 안달루시아) — 로마 집시 + 무어/유대 음악 융합 → 20세기 누에보 플라멩코
  • 샹송 전통 (프랑스) — 시적 가사 중심의 카바레 음악
  • 슐라거 전통 (독일어권) — 단순하고 감상적인 멜로디의 대중가요, 미국 팝 도입 이전부터 존재

1. 프랑스: 샹송 계열

카바레 음악 (19세기 말, Belle Époque)
        │
    샹송 (Chanson, 1930s~, Édith Piaf) — 시적 가사 + 오케스트라 반주
        │
        ├─ 예술가곡풍 샹송 (Jacques Brel, Léo Ferré) — 문학적 가사 심화
        │
        └─ 예예 (Yé-yé, 1960s) — 미국/영국 팝 리듬 수용, 젊은 세대 대상
                │
                └─ 프렌치 팝/프렌치 터치 (French Touch, 1990s 말, Daft Punk, Air) — 디스코 샘플링 + 하우스

2. 영국: 자생적 록/포크 계열

브리티시 인베이전 (미국 로큰롤 역수입, 1960s 초)
        │
        ├─ 브리티시 블루스 붐 → 하드록 (미국 계보 5번에서 이미 다룸)
        │
        ├─ 브리티시 포크 리바이벌 (1960s, Fairport Convention) — 켈트/잉글리시 민요 + 포크록
        │       └─ 프로그레시브 포크 → 이후 뉴 포크(2000s, Mumford & Sons류)
        │
        ├─ 스카/투톤 (Ska/2 Tone, 1960s~70s 말) — 자메이카 스카 + 영국 펑크 정서
        │       └─ 투톤 스카 (The Specials, 1979) — 인종 통합 메시지
        │
        ├─ 브릿팝 (Britpop, 1990s 중반, Oasis, Blur) — 영국적 정체성 강조, 미국 그런지에 대한 반작용
        │
        └─ 영국 도시음악 계보 (자메이카 사운드 시스템 + 힙합의 영국식 변용)
                │
                ├─ 정글/드럼앤베이스 (Jungle/DnB, 1990s 초) — 브레이크비트 가속화
                ├─ UK 개러지 (UK Garage, 1990s 말) — 하우스 + R&B 보컬 샘플
                │       └─ 그라임 (Grime, 2000s 초, 런던 동부) — UK 개러지 + 힙합 + 정글의 공격적 융합
                │               └─ UK 드릴 (2010s 중반) — 시카고 드릴 영향 + 그라임 정서
                └─ 덥스텝 (Dubstep, 2000s 초, 남런던) — 자메이카 덥 + UK 개러지의 저음 중심 실험

3. 독일어권: 슐라거 → 크라우트록 → 테크노 계열

슐라거 (Schlager, 20세기 초~)
        │

  2. 자메이카 리듬 문화 → 영국 도시음악: 이민을 매개로 한 계보 이식
  3. 스웨덴 팝 프로덕션 → 전 세계: 특정 스튜디오/작곡가 그룹이 장르가 아닌 "제작 방법론"으로 수출된 드문 사례
  4. 슐라거/칸초네 계열: 록/힙합의 세계적 헤게모니와 무관하게 각국 내수 시장에서 독자 생존한 계보

유럽은 미국처럼 하나의 인구 이동사(대이동, 노예제)로 수렴되지 않고, 국가·언어권별로 계보가 상당히 독립적으로 흘러가다가 특정 지점(레게의 영국 유입, 크라우트록의 미국 역수출 등)에서만 교차하는 구조임.

유럽 전통음악

유럽의 "전통음악"은 두 갈래로 나눠 봐야 정확함: ① 문자로 기보되고 작곡가 개인이 특정되는 서양 예술음악(클래식) 전통, ② 구전으로 전승되며 지역·공동체에 귀속되는 민속음악 전통. 두 갈래는 독립적으로 발전하다가 낭만주의 시기에 본격적으로 교차함.

1. 서양 예술음악(클래식) 계보

그레고리오 성가(Gregorian Chant, 9세기경 정리) — 단선율, 교회선법(모드) 체계
        │
    중세음악(Medieval, ~1400) — 다성음악의 발생 (오르가눔 → 모테트)
        │
    르네상스(Renaissance, 1400~1600) — 팔레스트리나 등, 대위법 정교화, 세속 마드리갈 발전
        │
    바로크(Baroque, 1600~1750) — 통주저음, 오페라 탄생(몬테베르디), 협주곡 형식 확립
        (바흐, 헨델, 비발디)
        │
    고전주의(Classical, 1750~1820) — 소나타 형식 확립, 조성음악의 정점
        (하이든, 모차르트, 베토벤)
        │
    낭만주의(Romantic, 1820~1900) — 개인 감정 표현 극대화, 반음계 확장, 표제음악
        (쇼팽, 슈만, 브람스, 바그너, 차이콥스키)
        │
        ├─ 국민악파(1800s 후반) — 각국 민속음악 선율을 예술음악에 적극 도입
        │       (드보르자크-체코, 그리그-노르웨이, 시벨리우스-핀란드,
        │        무소륵스키·림스키코르사코프 등 러시아 국민악파)
        │       — 여기서 처음으로 클래식과 민속음악 전통이 본격 교차함
        │
        └─ 인상주의(드뷔시, 라벨) — 조성 해체의 시작
                │
                └─ 20세기 현대음악 — 조성 해체 가속
                        ├─ 무조/12음 기법(쇤베르크) → 세리얼리즘
                        ├─ 신고전주의(스트라빈스키, 라벨 후기)
                        ├─ 미니멀리즘(라이히, 글래스, 미국 쪽으로 계보 이동)
                        └─ 전자음악/구체음악(1950s, 프랑스 슈토크하우젠·불레즈 등)
                                └─ 크라우트록 경유 → 미국 테크노에 영향 (유럽 대중음악 계보도 참조)

2. 민속음악 전통 (지역별)

유럽 민속음악은 하나의 계보로 수렴하지 않고 지역별로 독립적으로 존재하다가, 20세기 포크 리바이벌 시기에 각각 재조명되었음.

켈트 민속음악 (아일랜드·스코틀랜드·브르타뉴)
        — 지그(jig)·릴(reel) 등 춤곡 리듬, 도리안/믹솔리디안 등 교회선법 잔존
        └─ 1960년대 포크 리바이벌(Fairport Convention 등)에서 재조명 → 이후 켈틱 록/뉴에이지로 상업화

발칸 민속음악 (불가리아·세르비아·루마니아 등)
        — 홀수박자(7/8, 9/8 등) 리듬, 로마(집시) 브라스밴드 전통과 밀접
        └─ 이후 발칸 브라스(고란 브레고비치 등)로 세계화

플라멩코 (스페인 안달루시아)
        — 로마 집시 + 무어(이슬람) + 유대 음악 융합, 칸테(노래)·토케(기타)·바일레(춤) 삼위일체
        └─ 20세기 파코 데 루시아 등이 재즈 화성을 도입해 누에보 플라멩코로 확장

노르딕/스칸디나비아 민속음악
        — 피들(fiddle) 중심, 폴스카(polska) 등 3박 계열 춤곡
        └─ 현대 노르딕 포크(바르뉘트, 힘두르 등)로 이어짐

지중해/발칸 사이의 그리스 레베티코(rebetiko)
        — 오스만 제국 치하 도시 하층민 음악, 부주키(bouzouki) 중심
        └─ 그리스 근대 대중음악(라이코)의 직접적 뿌리

앵글로-켈틱 발라드 전통 (잉글랜드)
        — 애팔래치아를 거쳐 미국 컨트리/블루그래스의 뿌리가 됨 (미국 음악 계보도 참조)

3. 교차 지점: 두 전통이 만나는 곳

  1. 국민악파 — 클래식 작곡가들이 처음으로 민속 선율을 예술음악 어법에 정식 도입
  2. 바르톡·코다이(헝가리) — 20세기 초 민속음악을 학술적으로 채보·연구(비교음악학의 시초)하며 이를 작곡에 통합, 민속음악 연구와 클래식 작곡이 만나는 결정적 지점
  3. 포크 리바이벌(1950~60s) — 민속음악이 클래식이 아니라 대중음악(포크 록) 쪽과 결합하며 재조명된 20세기의 경로 (유럽 대중음악 계보도의 브리티시 포크 리바이벌 참조)
  4. 전자음악(뮤지크 콩크레트) — 클래식 최전선의 실험이 이후 크라우트록·테크노를 거쳐 대중음악으로 흘러들어간 사례

4. 교차 요약

  1. 클래식과 민속음악은 원래 별개의 계보: 하나는 개인 작곡가·기보 전통, 하나는 구전·공동체 전통 — 국민악파 이전까지는 거의 교류가 없었음
  2. 바르톡의 이중적 위치: 작곡가이자 최초의 체계적 민속음악 채록자로서, 두 전통을 잇는 유일무이한 인물
  3. 20세기 클래식의 실험이 대중음악으로 흘러간 경로: 뮤지크 콩크레트 → 크라우트록 → 테크노라는 예상 밖의 계보
  4. 유럽 민속음악의 지역적 파편성: 미국처럼 하나의 이주사로 수렴되지 않고, 각 지역이 20세기 들어 각자의 방식(포크 리바이벌, 발칸 브라스, 누에보 플라멩코 등)으로 재조명됨

국민악파 개별 작곡가의 민속 선율 인용 방식(드보르자크의 보헤미아 민요 vs 그리그의 노르웨이 민요)이나, 바르톡의 민속음악 채보 방법론, 발칸 리듬의 세부 박자 구조 등은 더 깊게 팔 수 있는 지점임.

동아시아

한국 대중음악

0. 뿌리: 전통음악

  • 판소리 — 서사적 구술 전통, 이후 트로트/국악가요의 발성·시김새에 영향
  • 민요 (경기민요, 서도민요, 남도민요 등 지역별 토리) — 신민요·트로트 양쪽에 선율적 뿌리 제공
  • 정악/시나위/산조 — 궁중·풍류 음악, 대중음악과의 직접 연결고리는 약하나 국악가요 부흥 시기에 재조명됨

1. 신민요 (1930년대)

일제강점기 유행가(트로트)와 쌍벽을 이룬 대중가요 양식으로, 민요의 어법을 적극 계승했음. 전통 선율악기(피리·단소·가야금)와 서양 악기를 혼합 편성한 반주가 특징이며, 박부용·왕수복·선우일선 등 권번 출신 '기생가수'들이 주역이었음. 1960년대에도 남도창을 가세한 형태로 이어졌으나 1970년대 이후 대중음악계에서 전통 소재를 다루는 흐름 자체가 약화되며 쇠퇴했음.

민요 + 서양 대중음악 형식
        │
    신민요 (1930s) — 경서도창 중심
        │
        └─ 1960년대 신민요 (남도창 가세) → 1970년대 이후 쇠퇴, 국악가요로 명맥만 이어짐

2. 트로트 (1930년대~현재)

트로트의 기원은 한국 대중음악사에서 가장 오래된 논쟁거리 중 하나임. 명칭 자체는 서양 춤곡 폭스트롯(fox trot)에서 왔지만, 2박자라는 공통점 외에는 실질적 관련이 없다는 게 학계 정설임.

일본 엔카와의 관계는 단순한 "영향 받음"이 아니라 상호 영향 관계로 보는 것이 최근 학계 흐름임. 엔카의 아버지로 불리는 작곡가 고가 마사오(古賀政男)는 어린 시절 경기도에서 자라며 경기민요의 영향을 받았다고 스스로 밝힌 바 있어, 엔카 쪽이 오히려 한국 민요의 영향을 받았다는 설도 학술적으로 논의됨. 초기 트로트(3박자 계열, '아리랑'식 리듬)와 엔카(2박자 계열)는 리듬 구조부터 차이가 있었고, 가사도 트로트는 항일 정서, 엔카는 연가(戀歌) 중심으로 결이 달랐음. 이후 번안곡 교환 등을 통해 서로 수렴하며 경계가 모호해진 것임.

1930년대~1960년대 중반까지는 '트로트'라는 이름 자체가 없었고 '가요', '유행가'로 불렸으며, 1960년대 후반 포크/발라드 등 새 장르가 유입되며 구분을 위해 '트로트'라는 이름이 붙기 시작했음.

민요 + 서양 블루스 계통 + 일본 엔카 (상호영향)
        │
    트로트 (1930s, 당시 명칭은 '유행가')
        │
        ├─ 1950년대: 신민요/스탠더드팝과 경쟁
        ├─ 1960년대 후반: '트로트'라는 명칭 정착 (포크/발라드와 구분 목적)
        ├─ 1970년대 중반: 부활, 서브장르 분화
        │       (엘레지 트로트, 블루스 트로트, 국악 트로트, 록 트로트/트로트 고고,
        │        포크 트로트, 댄스 트로트/세미 트로트 등)
        └─ 1980년대 이후: 비주류화 → 2010년대 말~2020년대 오디션 프로그램 통해 재부상

3. 스탠더드팝 (1950년대)

주한 미8군 무대를 통해 유입된 재즈풍 대중음악. 트로트('뽕짝')와 경쟁 구도를 이루었으나 1970년대 들어 몰락한 뒤 독자적 계보로는 부활하지 못했음. 다만 이 시기 미8군 무대 경험을 가진 연주자·작곡가들이 이후 포크·발라드·가요 편곡 전반에 재즈 화성을 이식하는 통로 역할을 했음.

4. 포크송 → 그룹사운드 → 발라드 계열

1960년대 후반 포크송 (통기타 문화, 한대수·김민기·양희은 등) — 미국 포크 리바이벌 영향
        │
        ├─ 대학가 청년문화·통기타 문화의 상징으로 자리잡음
        │
        └─ 그룹사운드/한국 록 (신중현 등) — 사이키델릭 록 + 소울/훵크 요소 국내 이식
                │
    (포크 + 그룹사운드의 서정적 요소가 1980년대에 수렴)
        │
    발라드의 태동 (1980년대 초, 조용필·김현식·조덕배·한영애 등)
        — 포크송/R&B 형식이었으나 트로트적 창법('뽕끼')에서 완전히 벗어나지는 못한 과도기
        │
    현대식 발라드의 확립 (1987, 유재하 「사랑하기 때문에」)
        — 클래식/오케스트라 선율, 단조 대신 장조 코드 선호, '브릿지' 형식을 한국 가요 최초로 도입
        │
        ├─ 이문세×이영훈 듀오 — 포크송·블루스 영향의 서정적 발라드로 또 다른 축 형성
        │
        └─ 1990년대 발라드 황금기 (임창정, 박효신, 나얼, 신승훈, 조성모 등)
                │
                ├─ 록발라드 (부활, 이승철 등) — 하드록/메탈 밴드의 파워발라드 어법 수용
                │       └─ 2000년대 초 록발라드 (버즈, MC더맥스 등) → 2002~2003년 '소몰이창법'
                │               유행 이후 소울/R&B 창법 솔로 가수들에게 주류 자리를 내주며 쇠퇴
                │
                └─ 2010년대 이후 정통 발라드 계보 — 폴킴, 규현, 정승환, 박재정 등으로 명맥 유지
                        (아이유 「밤편지」 등 포크발라드 시도도 간헐적으로 이어짐)

5. 댄스가요 → K-pop 아이돌 계보

1992년 서태지와 아이들 — 미국 힙합/뉴잭스윙 리듬 + 사회비판적 가사 국내 최초 결합
        │
    1990년대 댄스가요 열풍 + 1세대 아이돌 (H.O.T., 젝스키스, S.E.S., 핑클 등)
        — 미국/일본 아이돌 시스템 참고, SM/DSP 등 기획사 중심 육성 시스템 확립
        │
    2세대 아이돌 (2000년대 중후반, 동방신기, 빅뱅, 소녀시대, 원더걸스 등)
        — 유로댄스/유로팝 프로덕션(스웨덴 작곡팀 등) 본격 유입, 해외(일본·미국) 진출 시도
        │
    3세대 아이돌 (2010년대 초중반, 엑소, 방탄소년단, 트와이스, 레드벨벳 등)
        — 힙합/트랩 비트, 유튜브·SNS 기반 글로벌 팬덤 확산, 방탄소년단의 빌보드 진입으로 분기점
        │
    4세대 아이돌 (2010년대 말~2020년대 초, 에스파, 뉴진스, 스트레이 키즈 등)
        — 장르 혼종성 심화(하이퍼팝, UK 개러지, 이지리스닝 재유입), 세계관/멀티버스 서사 결합
        │
    5세대 아이돌 (2020년대 중반~) — 진행 중인 갈래, Y2K 리바이벌·저지클럽·아마피아노 등
        해외 리듬 트렌드의 발 빠른 이식이 특징으로 거론됨

6. 한국 힙합

1980년대 말~90년대 초 미국 힙합 국내 수용 (홍서범, 서태지와 아이들의 랩 파트 등 과도기)
        │
    언더그라운드 힙합 씬 형성 (1990년대 말~2000년대, 가리온, 다이나믹 듀오, 에픽하이 등)
        — 홍대 클럽 문화 기반, 재즈/소울 샘플링 중심 (미국 골든에이지 힙합 영향)
        │
        ├─ 리스너 힙합/붐뱁 계열 지속
        │
        └─ 오디션/서바이벌 프로그램화 (2012~, 쇼미더머니) — 트랩 비트 본격 유입, 스웨그/플렉스 문화 확산
                └─ 힙합의 주류 예능화 — 아이돌 그룹 내 래퍼 포지션과의 경계 모호화

7. 국악가요 (얼터너티브 국악)

신민요와는 별개로, 1990년대 후반 소리꾼 김용우를 기점으로 전통 창법(정가·민요)과 양악기(피아노·바이올린·신디사이저)를 결합한 새로운 시도가 이어졌음. 이는 이후 2010~2020년대 이날치, 잠비나이 등 전통 악기 기반 퓨전 국악 밴드로 계승되는 흐름의 선구적 사례로 평가됨.

8. 교차 요약

  1. 트로트 ↔ 엔카: 일방적 영향이 아니라 상호 형성 관계 — 학계에서도 아직 "명료하게 정리된 정설"은 없다고 보는 것이 정확함
  2. 포크 → 발라드: 통기타 서정성이 유재하를 거치며 화성적으로 정교화된 계보
  3. 미8군 스탠더드팝: 독자 장르로는 소멸했지만 재즈 화성을 국내 가요 편곡에 이식한 '숨은 통로'
  4. 서태지 이후 아이돌 시스템: 미국 리듬(힙합/R&B)의 수입 속도가 세대를 거듭할수록 빨라지는 구조 — 4~5세대에서는 거의 실시간 이식 수준

한국 전통음악(국악)

국악은 크게 전통적 분류법(아악·당악·향악)과 현대적 분류법(정악·민속악)으로 나뉨. 현대에는 후자가 표준으로 쓰임.

0. 전통적 삼분류: 아악·당악·향악

아악(雅樂) — 중국 주나라 유교 의례음악의 계승
        │
    고려 예종 11년(1116) 송나라에서 '대성아악(大晟雅樂)' 수입
        │
    조선 세종 때 박연이 고증을 통해 재정비 — 문묘제례악·사직제례악 두 계통으로 확립
        (사직제례악은 고려 때 아헌·종헌·송신에 향악을 섞어 쓰다가, 세종대 아악 정비 사업을 통해
        아악 일색으로 정리됨 — 7음계·기조필곡 등 아악 형식 원리를 그대로 따름)
        │
    일제강점기 — 환구단·사직 제사가 폐지되며 사직제례악 소실, 문묘제례악만 명맥 유지
        │
        └─ 2014년 사직제례악 복원 — 현재는 문묘제례악·사직제례악 두 계통이 함께 전승됨

당악(唐樂) — 통일신라 이후 중국에서 유입
        │
    고려시대 송의 사악(詞樂) 수용 → 당악으로 통칭
        │
    조선시대 향악화 진행 (황종음이 C인 당악계 vs E♭인 향악계로 음계 구분)
        │
    현재 남은 것은 〈보허자〉·〈낙양춘〉 단 2곡
        └─ 다만 그 파생곡인 〈여민락〉·〈수제천〉·〈천년만세〉 등은 향악화되어 지금도 연주됨

향악(鄕樂) — 한반도 토착 음악 + 통일신라 이전 유입된 외래음악 전반
        │
    신라 눌지왕 때 〈우식악〉이 최초 기록
        │
    삼국시대 각국 향악(고구려·백제·신라)이 고려 조정에 계승
        │
    조선시대 세종이 〈정대업〉·〈보태평〉 등 신악(新樂) 대거 창작
        — 이후 세조 때 종묘제례악으로 채택되어 오늘날까지 연주됨
        │
        └─ 오늘날 가장 큰 비중을 차지하는 궁중음악 갈래

1. 현대 분류: 정악(正樂) vs 민속악(民俗樂)

1909년 조양구락부, 1911년 정악전습소 설립을 계기로 '정악'이라는 명칭이 공칭화되었음. 아악·당악·향악의 구분이 사실상 무의미해진(아악 1곡, 당악 2곡만 남음) 근대 이후, 계층(상류층 vs 서민)을 기준으로 한 정악/민속악 이분법이 표준 분류로 자리 잡았음.

1-1. 정악 계열 (궁중·풍류방 음악)

정악
        │
        ├─ 궁중음악 — 종묘제례악, 문묘제례악, 여민락, 수제천 등
        │
        └─ 풍류방 음악(선비들의 실내악)
                ├─ 성악: 가곡, 가사, 시조
                └─ 기악: 줄풍류(거문고 중심 현악합주), 대풍류(삼현육각), 영산회상

1-2. 민속악 계열 (민간 음악)

민속악
        │
        ├─ 성악
        │       ├─ 판소리 — 소리꾼 1인 + 고수 1인의 서사 음악(창·아니리·너름새)
        │       │       └─ 병창(가야금 반주로 판소리 대목을 노래) — 산조와 결합된 형태
        │       ├─ 민요 — 지역별 '토리'(경기토리·서도토리·남도토리·동부토리 등)
        │       ├─ 잡가 — 전문 소리꾼의 좌창/입창
        │       └─ 무가(巫歌) — 무속 의식에서 불리는 노래
        │
        └─ 기악
                ├─ 산조(散調) — 가야금·거문고·대금 등의 기악 독주곡, 스승의 가락에
                │       제자가 자신의 가락을 더해 새 유파를 형성하는 즉흥연주 전통
                ├─ 시나위 — 무속 반주에서 발전한 즉흥 합주곡
                └─ 농악 — 타악기 중심의 야외 합주(전북·전남·경남·경북·충북·영동 농악 등)

* 범패(불교 의식음악)는 민속음악에 편의상 포함되기도 하나, 본래 민중이 향유한 음악은 아니라는 점에서 별도 분류하기도 함

2. 교차 요약

  1. 아악·당악의 사실상 소멸: 향악화가 진행되며 원래의 아악(1곡)·당악(2곡)만 순수하게 남고, 나머지는 모두 향악의 파생곡으로 흡수됨
  2. 즉흥연주와 유파 형성: 산조·판소리의 '더늠'(자신의 소리를 더해 확장) 전통은 서양 클래식의 작곡가-연주자 분리 구조와 근본적으로 다른 한국음악 특유의 생성 방식
  3. 정악/민속악 이분법의 한계: 범패 같은 종교음악이나 창작국악은 이 틀에 깔끔하게 들어가지 않음 — 학계에서도 여전히 논의 중인 분류 문제

한국 작곡가·작사가 계보

'사단'이라는 표현은 레코드사/기획사 중심으로 특정 창작자가 여러 스타 가수를 거느리는 한국 가요계 특유의 구조를 가리키는 말로, 실제로 '박춘석 사단', '신중현 사단'처럼 학계·언론에서도 공식적으로 쓰임. 시대별로 정리했음.

1. 일제강점기 (1920s~1945)

작곡가

  • 박시춘 — 데뷔작 〈항구의 선술집〉, 〈물방아 사랑〉. 감각적이고 세련된 선율이 특징. 조명암과 명콤비.
  • 손목인 — 〈타향살이〉, 〈바다의 교향시〉
  • 전수린 — 〈황성옛터〉 등 신민요풍 트로트의 초기 대표작
  • 김해송 — 〈선창〉(고운봉) 작곡. 이난영의 남편이자 다재다능한 작·편곡가
  • 이재호 — 태평레코드 소속, 이후 1950~60년대까지 활동 지속
  • 이봉룡 — 〈목포는 항구다〉(이난영), 〈낙화유수〉(남인수)

작사가

  • 조명암 — 오케레코드 소속. 〈선창〉, 〈목포는 항구다〉, 〈알뜰한 당신〉, 〈꿈꾸는 백마강〉 등 600여 곡. 월북 이후 1965~1992년 금지곡 처리되었다가 해금. 시인으로도 등단한 문인 출신.
  • 박영호 — 태평레코드 문예부장 겸 작사가
  • 반야월(진방남) — 가수 겸 작사가로 활동 시작, 해방 이후 5,000여 곡을 남기며 '한국 가요계 3대 보물'(박시춘·이난영과 함께)로 불림
  • 유도순, 김능인, 왕평 — 초창기 신민요·유행가 작사 주역

레코드사 사단 (음반사가 곧 창작 집단이었던 구조)

  • 오케레코드(이철 사단) — 사장 이철이 조명암을 발탁, 손목인·이봉룡·박시춘 등과 함께 〈목포는 항구다〉·〈낙화유수〉 등 대표작 배출
  • 태평레코드 — 이재호(작곡)·박영호(작사) 중심
  • 빅터·콜롬비아 레코드 — 전수린 등 소속

2. 해방 이후~1950년대: 트로트 지속 + 스탠더드팝 태동

  • 박시춘·이재호·손목인·반야월 등 일제강점기 인물들이 그대로 가요계 주축으로 이어짐 (조명암·박영호는 월북)
  • 박춘석 — 1954년 데뷔, 미8군 무대 출신 재즈 피아니스트로 출발. 이후 최대 히트 작곡가로 성장
  • 길옥윤 — 재즈 색소포니스트 출신, 일본에서 활동 후 귀국

3. 1960~70년대: 트로트 황금기 + 록/포크의 태동

박춘석 사단

  • 박춘석 — 개인 최다 2,700여 곡 작곡. 1966년 지구레코드 이적을 계기로 '박춘석 사단' 형성
  • 사단 구성원: 이미자(〈동백아가씨〉는 백영호 곡이지만 이미자의 대표 프로듀서는 박춘석), 패티김, 남진, 나훈아, 문주란, 하춘화, 정훈희
  • 대표작: 〈섬마을 선생님〉, 〈가슴 아프게〉, 〈마포종점〉

백영호

  • 박춘석과 '트로트 쌍벽'으로 불림. 〈동백아가씨〉, 〈여자의 일생〉, 〈황포돛대〉(모두 이미자)

길옥윤·이봉조 — 재즈 기반 작곡가

  • 길옥윤 — 패티김과 콤비 활동 후 1972년 결별, 이후 혜은이와 〈제3한강교〉, 〈당신은 모르실거야〉
  • 이봉조 — 색소포니스트 출신, 정훈희와 함께 국제가요제 다수 입상 (〈안개〉 등)

신중현 사단 — 한국 록의 태동

  • 신중현 — '한국 록 음악의 대부'. 최초의 록그룹 '애드포' 결성, 이후 펄시스터즈·김추자·박인수 등 다수 가수 프로듀싱
  • 사단 구성원을 통해 록/소울 어법을 대중가요에 최초로 이식

통기타 포크 계열

  • 청년문화의 상징으로 독자적인 싱어송라이터 문화 형성 (한대수, 김민기, 양희은 등 — 특정 '사단' 구조보다는 개별 창작자 중심)

4. 1980년대: 발라드의 확립

  • 유재하 — 1987년 〈사랑하기 때문에〉로 한국형 팝 발라드 개척. 요절했으나 이후 세대에 절대적 영향
  • 이영훈 — 이문세와 공동 작업으로 발라드 황금기 견인. 2011년 '대중음악 사운드' 설문 '최고의 작곡가 10'에 신중현·박춘석·이봉조·박시춘 등과 함께 선정
  • 이 시기는 특정 '사단'보다는 이영훈-이문세, 유재하 개인 서명이 뚜렷한 시기

5. 1990년대: K-pop 태동기 — '5대 작곡가' 체제

1992년 서태지와 아이들 데뷔를 기점으로 나이트클럽 DJ 출신 작곡가들이 대거 제작자로 전환되며 이른바 5대 작곡가로 불린 인물들이 가요계를 주도했음:

  • 김창환 — DJ 출신, 박미경을 댄스가수로 전환
  • 최준영 — DJ 출신
  • 주영훈
  • 윤일상
  • 김형석 — 발라드 명곡 다수(이문세, 임재범, 신승훈, 성시경, 조성모 등), 이후 김이나를 작사가로 발탁하며 방시혁·박진영에게도 프로듀싱을 전수한 '대스승'격 인물

이 시기 박진영도 작곡가 겸 가수로 데뷔, 이후 JYP엔터테인먼트를 세워 독자 사단 형성 시작

6. 2000년대~2010년대: 대형기획사 사단 체제 확립

SM엔터테인먼트

  • 유영진 — H.O.T. 프로듀싱을 시작으로 30년 넘게 SM 전속, 'SMP(SM Performance)' 사운드의 창시자. H.O.T.부터 에스파까지 전담
  • KENZIE — 유영진과 함께 SM 프로듀싱의 중추, Hearts2Hearts 등

JYP엔터테인먼트

  • 방시혁 — 1997~2005년 JYP 수석 프로듀서로 활동하며 박진영에게 프로듀싱 사사, god의 후속곡·수록곡 다수 담당. 2005년 독립해 빅히트(현 하이브) 설립, 방탄소년단 프로듀싱

YG엔터테인먼트

  • Kush, Choice37, G-DRAGON(자체 작사·작곡)

그 외 전담 작곡가 체제

  • 용감한 형제 — 브레이브걸스 등
  • 신사동호랭이 — EXID, 〈위아래〉 등 (K-POP 명곡100 작사/작곡 4위)

7. 교차 요약

  1. '사단' 구조의 연속성: 일제강점기 오케레코드(이철 사단) → 1960~70년대 박춘석/신중현 사단 → 2000년대 이후 SM/YG/JYP 프로듀서 체제까지, 한 명의 스타 창작자가 다수 가수를 전담하는 구조가 100년 가까이 이어짐
  2. 사제 관계로 이어지는 프로듀싱 계보: 김형석 → 박진영 → 방시혁으로 이어지는 '프로듀싱 사사' 관계는 학계에서도 자주 언급되는 흥미로운 대목
  3. 작사·작곡 분업의 시대별 변화: 일제강점기~1980년대까지는 작곡가/작사가가 뚜렷이 분리(조명암-박시춘, 이영훈이 드물게 겸업)되다가, 1990년대 이후 자체 작사·작곡을 겸하는 창작자(서태지, 박진영, G-DRAGON, RM 등)가 늘어남
  4. 정치적 단절의 흔적: 조명암·박영호 등 최상급 작사가들이 월북하며 1965~1992년 금지곡 처리된 것은 냉전이 대중음악 계보에 직접 영향을 미친 사례

0. 뿌리: 전통음악

  • 가가쿠(雅楽) — 궁중 아악, 이후 대중음악과 직접 연결고리는 약함

1. 엔카 (演歌)

메이지 시대 말기 자유민권운동가 가와카미 오토지로가 부른 〈옷페케페 타령〉 등 정치풍자 창가에서 출발했음. 다이쇼 시대 창가를 거쳐, 쇼와 시대 작곡가 고가 마사오(古賀政男)에 이르러 지금 알려진 형태의 엔카로 정착했음. 고가는 어린 시절을 조선 경기도에서 보내며 경기민요의 영향을 받았다고 스스로 밝힌 바 있어, 엔카 형성 자체에 한국 민요가 개입했다는 설이 학술적으로 논의된다(한국 트로트와는 상호 형성 관계).

요나누키 음계(펜타토닉)와 굴곡진 창법(고부시)이 특징이며, 술·눈물·이별·바다 등을 소재로 함. 1950~60년대 미소라 히바리의 등장으로 전성기를 맞아 이 시기 일본 대중음악은 사실상 엔카와 동의어였으나, 1970년대 후반 포크록·뉴뮤직의 등장으로 주류에서 밀려나 중장년층 음악으로 자리 잡았음.

창가/나니와부시 + 한국 민요적 영향(고가 마사오 경유)
        │
    엔카 (쇼와 초기 정착)
        │
    미소라 히바리 시대 (1950s~60s) — 일본 대중음악=엔카였던 전성기
        │
        └─ 1970년대 후반 포크록/뉴뮤직에 주류 자리를 내주며 중장년 장르로 고착

2. 가요쿄쿠 (歌謡曲)

1920년대~1980년대까지 일본 대중음악 전반을 포괄하던 용어로, 엔카를 포함해 서양 팝/재즈 영향을 받은 모든 유행가를 지칭했음. J-POP이라는 용어가 1990년대에 이를 대체하기 전까지 일본 대중음악의 표준 명칭이었음.

  2. 핫피 엔도: 일본어 록 가사의 예술적 완성도를 확립한 결정적 분기점
  3. 시티팝: 하나의 장르가 아니라 뉴뮤직 내부의 사운드 지향(미국 AOR·퓨전 지향)으로 이해하는 것이 정확함
  4. YMO → 세계 일렉트로니카: 크라우트록의 영향을 받아 다시 세계 초기 테크노/디스코에 영향을 준 순환 사례

참고 자료

  • 나무위키 「일본 음악」, 「엔카(장르)」, 「시티 팝」, 「J-POP」 항목
  • 위키백과 「City pop」, 「J-pop」 항목

시티팝이 장르인지 사조인지에 대한 논쟁, 엔카/트로트 상호형성론의 세부 논거, 자니스 시스템과 한국 아이돌 시스템의 구조적 차이 등은 각각 더 파고들 여지가 있음.

일본 전통음악

일본 전통음악은 크게 고대(아스카~헤이안), 중세(가마쿠라~무로마치), 근세(에도)로 시대구분되며, 각 시대의 음악이 폐기되지 않고 현재까지 나란히 전승된다는 것이 가장 큰 특징임. 넓은 의미의 '호가쿠(邦樂)'가 이 전체를 아우르는 명칭임.

0. 고대: 가가쿠(雅樂)의 성립

일본 고유 음악 — 와곤(和琴) 등 조몬~야요이 시대 토착 악기
        │
    5세기 신라 악인·악기 도입, 6세기 백제 악인 왕래 기록
        │
    612년 백제인 미마지(味摩之)가 기악(伎樂) 전수
        │
    701년 가가쿠료(雅樂寮) 설치 — 삼국악(고구려·백제·신라)과 당악을 함께 교육
        │
    9세기 — 좌방악(左方樂, 당악·唐樂 계열)과 우방악(右方樂, 고마가쿠·高麗樂=삼국악 계열)의
        이원 체제로 정리, 현재까지 이 구조 유지
        │
    가가쿠 = 관현(管絃, 기악 합주) + 무악(舞樂, 무용 반주)
        + 성악 갈래(카구라우타·아즈마아소비 등 토착 레퍼토리, 사이바라·로에이 등 궁정 성악)
        │
        └─ 현존하는 세계 최고(最古)의 관현합주 전통으로 평가됨

1. 중세: 노가쿠(能樂)와 비와가쿠(琵琶樂)

무로마치 시대(1333~1573) 사무라이 계층의 후원
        │
    노가쿠(能樂) — 노(能)와 교겐(狂言)으로 구성된 가면극, 자유리듬(장단 없는 리듬) 사용이 특징
        — 고도로 훈련된 배우·연주자가 필요한 종합 예술

비와가쿠(琵琶樂) — 비와호시(琵琶法師, 비파 연주하며 이야기하는 순회 예능인)
        │
        └─ 헤이케 이야기(平家物語) 낭송 전통 — 13세기 초 시각장애인 길드로 조직되며 확산
                └─ 후대 치쿠젠비와(筑前琵琶)·사쓰마비와(薩摩琵琶) 등 지역 유파로 분화

2. 근세(에도 시대): 샤미센 음악의 폭발적 분화

샤미센(三味線, 오키나와 산신에서 유래해 개량된 3현 악기) 도입
        │
        ├─ 조루리(浄瑠璃) — 샤미센 반주의 이야기 음악
        │       │
        │       ├─ 고조루리(古浄瑠璃) — 초기 형태
        │       │
        │       └─ 기다유부시(義太夫節, 다케모토 기다유 창시, 1684~)
        │               — 지카마쓰 몬자에몬의 각본으로 인형극(닌교조루리/분라쿠)에 정착
        │               — 말(대사)의 비중이 노래보다 커서 '가타리모노(語り物)'로 분류
        │               — 가부키에 도입되어 '다케모토(竹本)'로 불림
        │
        └─ 나가우타(長唄) — 도쿄에서 발전, 가부키 무용 전속 음악
                — 오키·미치유키·구도키·오도리지·지라시·단키레의 6부 구성
                — '우타이모노(唄物)': 대사보다 노래 비중이 큼 (기다유부시와 대비되는 축)

가정음악(교양 음악)
        │
        ├─ 고토(箏, 13현 발현악기) — 가정 내 여성 교양 음악으로 정착
        ├─ 샤쿠하치(尺八) — 승려 수행 도구에서 가정음악으로 확장
        └─ (고토·샤미센·샤쿠하치 삼중주 = '산쿄쿠三曲' 편성으로 발전)

성악: 쇼묘(聲明) — 불교 의식 음악, 백제·당에서 전래된 불교와 함께 유입

3. 근대 이후: 민요와 신민요, 엔카로의 분기

민요(民謠) — 각 지역 노동요·의식요, 요나누키(4·7음 제외) 5음계 사용
        │
    메이지 시대 창가(唱歌) 운동 — 서양식 학교 음악교육 도입
        │
    엔카(演歌)의 성립 — 정치풍자 창가 → 다이쇼 창가 → 고가 마사오(古賀政男)를 거쳐
        요나누키 음계 기반의 현재 형태로 정착 (일본 대중음악 계보도에서 상세히 다룸)
        │
        └─ 전통음악(가가쿠·노가쿠·샤미센 음악)과는 별도 계보로, 대중가요 영역에서
                민요의 정서와 음계를 계승하는 역할을 함

4. 교차 요약

  1. 좌방악/우방악 체계: 당악과 삼국악(한반도 음악)이 나란히 궁중음악의 두 축으로 편입된 고대 동아시아 음악 교류의 직접적 증거
  2. 기다유부시 vs 나가우타: 같은 샤미센 반주 음악이면서도 '말 중심(가타리모노)'과 '노래 중심(우타이모노)'으로 미학적으로 갈라진 대표 사례
  3. 폐기되지 않는 전승 구조: 가가쿠(8세기)부터 나가우타(18세기)까지 어느 것도 이전 것을 대체하지 않고 나란히 현재까지 전승 — 한국의 정악/민속악처럼 계층별로 병존하는 구조와 유사하나 시대층이 더 세분화되어 있음
  4. 민요-엔카: 순수 전통음악과 근대 대중음악 사이의 유일한 직접적 다리 역할

  • 한경대학교 개설 강의자료 「일본의 민속음악」 (KOCW)
  • 일본예술문화진흥회 가부키 공식 해설자료

기다유부시와 가부키 게자(黒御簾) 음악의 세부 편성, 오키나와 민속음악(산신 중심)과 본토 음악의 차이 등은 더 들어갈 수 있는 지점임.

중화권 대중음악

중화권 대중음악은 20세기 중반 정치적 분단(국공내전, 이후 냉전)으로 계보가 대륙/대만/홍콩 세 갈래로 단절·분산되었다가, 1980~2000년대에 다시 수렴하는 독특한 구조를 가짐.

0. 뿌리: 전통음악과 시대곡의 탄생

  • 경극(京劇) 등 전통 희곡음악 — 대중가요와 직접 연결고리는 약하나 창법·정서의 배경
  • 한족 민가(民歌) — 지역별 민요, 이후 국풍(國風) 장르의 재료로 재소환됨
서양 재즈 + 상하이 댄스홀 문화 + 중국 민가
        │
    시대곡(時代曲, 1920s~40s, 상하이) — 중국 최초의 근대적 대중음악
        — 리밍후이 「모모위(毛毛雨)」 등이 초기 대표곡
        — '상하이 7대 가후(上海七大歌后)'로 불린 여성 가수들이 주역
        │
    (1949년 국공내전 종결 이후 계보 단절: 대륙/홍콩/대만으로 분산 이식)

1. 대륙: 혁명가곡 → 록 → 대륙 팝 계열

시대곡 전통의 대륙 내 단절 (1949 이후)
        │
    혁명가곡/정치가요 (1950s~70s) — 국가 주도 음악, 서양 팝 요소 배제
        │
    개혁개방 이후 서구 팝 재유입 (1980s)
        │
        ├─ 시베이펑(西北風, 1980s 말) — 서북 민가 + 록 편곡, 대륙 록의 토착화 시도
        │
        └─ 대륙 록 (추이젠 崔健, 1986 「一無所有」) — '중국 록의 아버지'로 불림,
                톈안먼 사건 전후 청년 세대의 정서적 목소리 역할
                │
                └─ 이후 대륙 인디/얼터너티브 록 씬 형성
        │
    1990s~2000s 대륙 팝 — 홍콩/대만 팝 프로덕션 방식 수입, 이후 C-pop으로 통합
        │
    국풍(國風, 2010s~) — 전통 악기(고쟁, 비파 등) 샘플링 + 힙합/일렉트로닉 비트 결합,
        한푸(漢服) 문화 부흥과 맞물려 유행

2. 홍콩: 캔토팝(廣東歌) 계열

시대곡 전통의 홍콩 이식 + 광동어 대중가요
        │
    캔토팝(Cantopop, 1970s~) — 광동어 대중음악, 1970~80년대 홍콩 영화 주제가와 결합하며 발전
        — 명칭 자체는 1970년대 홍콩 거주 광고기획자가 '빌보드 팝' 식으로 만든 조어에서 유래
        │
    황금기 (1980s~90s) — 사대천왕(四大天王: 장학우·유덕화·여명·곽부성) 시대,
        한국·일본·동남아까지 영향력 확산
        │
        └─ 1997년 홍콩 반환 이후 — 대륙 시장 개방과 맞물려 만다린팝으로 활동 축 일부 이동,
                2000년대 이후 캔토팝은 C-pop의 하위 갈래로 위상 축소

3. 대만: 만다린팝(國語流行歌曲) 계열

시대곡 전통의 대만 이식 (국민당 정부 이주와 함께)
        │
    초기 대만 가요 (1950s~60s) — 상하이 시대곡 스타일 계승, 일본 엔카 영향도 일부 유입(일제 식민 지배 잔재)
        │
    등려군(鄧麗君, 테레사 텐) 시대 (1970s~80s)
        — 대만·홍콩·대륙·일본·동남아를 잇는 범중화권 최대 스타
        — 원래 민요/팝/무드송 가수였으나 일본 진출 후 세련된 창법으로 재정립
        — 사후에도 '아시아의 가희'로 남중화권에 걸쳐 상징적 위상 유지
        │
    캠퍼스 포크송(校園民謠, 1970s 말~80s) — 미국 모던포크 영향, 대학생 중심의 서정적 자작곡 운동
        — 대만 자생 장르로, 1980년대 후반 대륙에 전파되며 '감성적 민족주의'의
          문화적 매개 역할을 했다는 평가도 있음
        │
        └─ 이후 대만 발라드/싱어송라이터 계보로 이어짐 (뤄다유 羅大佑 등)
                │
                └─ 1990s~2000s 만다린팝 황금기 (장혜매, 주걸륜, 채의림, F.I.R 등)
                        — 주걸륜(周杰倫)의 중국풍(中國風) 시도 — R&B/힙합 + 전통 오음계 결합,
                          이후 대륙 국풍 장르의 직접적 선구로 평가됨

4. C-pop으로의 수렴 (2000년대 이후)

대륙 팝 + 홍콩 캔토팝(위상 축소) + 대만 만다린팝
        │
    C-pop (중문유행음악, 中文流行音樂) — 대륙·홍콩·대만·마카오 및 싱가포르·말레이시아
        화교권까지 아우르는 포괄적 우산 용어로 통합
        │
        ├─ 만다린팝이 사실상의 표준어(음)가 되며 캔토팝은 정체성 유지형 하위 장르로 축소
        ├─ 대륙 스트리밍 시장 성장 이후 오디션 프로그램발 아이돌 그룹 등장 (한국 아이돌 시스템 영향)
        └─ 국풍/중국풍이 2010년대 이후 대륙-대만 공통의 '전통 재해석' 축으로 자리잡음

5. 교차 요약

  1. 시대곡의 삼분(三分): 하나의 상하이발 장르가 정치적 단절로 대륙/홍콩/대만 세 계보로 갈라졌다가 2000년대에 재수렴
  2. 등려군: 정치적으로 단절된 대만·홍콩·대륙·일본을 음악으로 연결한 유일무이한 매개체
  3. 주걸륜의 중국풍 → 국풍: 대만에서 시작된 '전통+힙합' 실험이 이후 대륙 국풍 장르의 직접적 원류가 됨
  4. 캔토팝의 성쇠: 1980~90년대 범중화권 헤게모니를 쥐었으나 1997년 반환 이후 만다린팝에 자리를 내준 유일한 사례

시대곡의 정치적 삼분 구조나 국풍 장르의 세부 계보(주걸륜 이후 힙합/트랩과의 결합), 캔토팝 황금기 프로덕션 방식 등은 더 깊게 팔 수 있는 지점임.

중국 전통음악

중국 전통음악은 보통 다섯 갈래로 분류됨: 민가(民歌), 가곡(歌曲/문인음악), 설창(說唱), 희곡(戲曲), 기악(器樂). 한국·일본 아악·향악 체계의 원류가 여기서 나왔다는 점에서 동아시아 전통음악 전체의 뿌리 격임.

0. 고대: 아악(雅樂)·속악(俗樂)의 원형

주(周)나라 유교 의례음악 — 아악(雅樂)의 원형, 삼분손익법(三分損益法)으로 음계 산출
        │
    한(漢)나라 — 대악서(大樂署) 설치, 종묘악 제도화
        │
    남북조 시대 — 남조는 아악·속악(청상삼조 등) 계승, 북조는 서역(인도·이란) 악무 대거 수입
        │
    수(隋)나라 — 서역음악과 중국 고유음악을 합쳐 칠부기(七部伎)로 정리 → 이후 구부기(九部伎)로 확장
        │
    당(唐)나라 — 십부기(十部伎)로 국제적 성격 정점, 아악은 악현(堂下)/등가(堂上) 이원 편성
        │
        └─ 이 시기 음악이 신라·발해를 거쳐 일본에 '도가쿠(唐樂)'로 전해짐 (일본 가가쿠의 핵심 축)

1. 문인음악(文人音樂): 고금(古琴) 계열

선비 계층의 수신(修身) 도구로서의 음악
        │
    고금(古琴, 칠현금) — 독주 중심, 여백과 절제의 미학
        │
        └─ 실(瑟)·쟁(箏) 등 발현악기 전통과 병행 발전
                └─ 쟁은 당대 이후 속악(민간음악)에 흔히 사용되며 문인음악과 갈라짐

2. 희곡음악(戲曲音樂): 지방극 계열

당대 변문강창(變文講唱, 절에서 승려가 불경을 노래로 풀어내던 형식) — 설창음악의 원류
        │
    송대 사(詞)·곡(曲) 창작 융성 (강기姜夔 등 사인 겸 음악가)
        │
    원대 잡극(雜劇) — 설창·가무·악기가 결합된 종합 연희로 발전
        │
    명대 곤곡(崑曲, 쿤취) — 장쑤성 쿤산 지방에서 발생, 여타 지방 극종을 압도하며 전국적 유행
        │
        └─ 청대 이후 각 지방 방언 기반의 지방희(地方戲) 분화
                └─ 경극(京劇, 베이징) — 여러 지방희가 궁정을 중심으로 융합되어 성립,
                        오늘날 가장 널리 알려진 중국 전통 극음악

3. 설창음악(說唱音樂): 곡예(曲藝) 계열

당대 변문강창에서 출발한 서사음악 갈래로, 한 명 혹은 소수의 연희자가 이야기를 말과 노래로 풀어내는 형식임. 쓰촨 콰이반(快板), 베이징 다구(大鼓), 쑤저우 핑탄(評彈) 등 지역별로 수백 종의 곡종(曲種)이 존재하며, 중국 서사 문화의 구술 전통을 음악적으로 계승한 갈래임.

4. 민가(民歌)와 기악(器樂) 계열

한족 각 지역 민가 (섬서·산시 신텐요우 信天遊, 강남 소조小調 등)
        │
        └─ 강남사죽(江南絲竹, 상하이·쑤저우 일대) — 현악기(絲)와 관악기(竹) 중심의 실내악 합주,
                온화하고 유려한 강남 지역색이 특징

기악 독주 전통 — 얼후(二胡), 피파(琵琶), 디쯔(笛子) 등
        └─ 아병영월(阿炳〈二泉映月〉) 등 근현대 얼후 독주곡이 20세기 이후 대표 레퍼토리로 정착

5. 근대 이후: 전통에서 대중음악으로의 분기 (참고)

1920년대 상하이 — 뤼진후이(黎錦暉) 등이 중국 전통 민요와 서양 춤곡(폭스트롯 등)을 결합 시도
        │
    시대곡(時代曲)의 탄생 — 전통음악과는 결이 다른 근대적 대중음악으로 분기
        (중화권 대중음악 계보도에서 상세히 다룸)
        │
    이 흐름과 별개로 전통음악 자체는 경극·강남사죽·기악 독주 등으로 독자적으로 존속
        │
    2000년대 이후 — 국풍(國風)/고풍(古風) 장르가 전통 선율·악기를 대중음악에 재도입하며
        전통과 대중의 재접속을 시도 (여자십이악방 등이 대표 사례)

6. 교차 요약

  1. 당대 십부기 → 동아시아 전파: 중국 궁중음악이 국제적 종합을 거쳐 한국·일본에 아악/당악 체계로 이식된 역사적 기점
  2. 곤곡 → 경극: 하나의 지방극이 전국구로 확산했다가, 이후 여러 지방희의 융합으로 다시 새로운 대표 극종(경극)이 탄생하는 순환
  3. 문인음악(고금) vs 민간음악(쟁): 같은 발현악기 계열이 계층에 따라 미학적으로 갈라진 사례
  4. 전통 vs 대중의 근대적 단절: 시대곡 이후 전통음악과 대중음악이 각자 독자 노선을 걷다가, 21세기 국풍 장르에서 다시 접속

참고 자료

  • 위키백과 「중국 음악」 항목
  • 중국유학 사이트 「중국 전통음악」 소개 자료
  • KCI 논문, 「중국의 서사(敍事)음악—곡예(曲藝)음악」

경극의 성부 체계(생生·단旦·정淨·축丑)나 강남사죽의 악기 편성, 국풍 장르의 세부 계보는 더 파고들 수 있는 지점임.

PLATE IV

아프리카

아프리카 음악

0. 공통 기반: 그리오, 폴리리듬, 콜앤리스폰스

아프리카 대중음악을 관통하는 세 가지 원리가 있음. 서아프리카의 그리오(Griot)는 세습되는 음유시인 계급으로, 코라·응고니 등을 연주하며 구술 역사와 계보를 노래로 전승한다(디아바테/Diabaté가 대표적 그리오 성씨). 여기에 여러 리듬 패턴이 동시에 겹치는 폴리리듬, 한 사람이 부르면 여럿이 화답하는 콜 앤 리스폰스 구조가 대륙 전역에 공통으로 흐르며, 훗날 블루스·재즈·삼바·살사 등 아메리카 대륙 음악 전반의 문법이 됨.

1. 서아프리카: 하이라이프 → 아프로비트 → 아프로비츠

하이라이프(Highlife, 가나, 1900s~) — 서구 브라스밴드 편성 + 아칸족 리듬
        │
주주 음악(Jùjú, 나이지리아) — 요루바족 타악기 전통 + 기타 중심 편곡
        │
        ├─ 아프로비트(Afrobeat, 1960s~70s) — 펠라 쿠티가 하이라이프 + 미국 재즈·훵크(제임스 브라운)를
        │       결합, 군사정권 비판이라는 정치성이 핵심. 드러머 토니 앨런이 리듬적 뼈대
        │
        └─ 아프로비츠(Afrobeats, 2010s~) — 아프로비트와 발음만 비슷할 뿐 다른 개념.
                하이라이프·주주·나이자비트·댄스홀·하우스가 뒤섞인 나이지리아·가나발 포괄적 사운드
                (위즈키드, 버나 보이 등)
                └─ 아프로팝(Afropop) — SNS 기반으로 전 세계에 퍼진 팝 지향 갈래

2. 서아프리카 내륙: 그리오 전통 음악 → 음발라

음바랑(Mbalax, 세네갈 토속 타악 리듬)
        │
    음발라(Mbalax, 대중음악화) — 쿠바 음악(역수입된 아프리카 리듬) + 서구 팝을 그리오 전통에 결합.
        유수 은두르가 세계적으로 대중화

3. 중앙아프리카: 콩고 룸바 → 수쿠스

노예제를 통해 아프리카에서 쿠바로 건너간 리듬이 손(Son)을 거쳐 쿠바 룸바로 정착했고, 1930~40년대 라디오·음반을 통해 다시 콩고로 역수입되며 새로운 장르로 재탄생한 순환 사례임.

쿠바 룸바의 역수입(1930s~40s) — 콩고 지역 방송·음반을 통해 쿠바 손·룸바가 유입
        │
    콩고 룸바(Rumba Lingala, 1950s~) — 쿠바 리듬 + 링갈라어 가사 + 전기기타
        │
        └─ 수쿠스(Soukous, 1960s~) — 템포 가속, 화려한 기타 솔로(세벤) 중심

4. 남아프리카: 마라비 → 콰이토 → 아마피아노

요하네스버그 금광 발견 이후 형성된 흑인 노동자 거주구 '타운쉽'에서의 혼종화가 출발점임.

마라비(Marabi, 19세기 말~) — 타운쉽 무허가 술집 '쉬빈'에서 발전, 초기 재즈(래그타임) +
        남아공 전통음악의 구전 혼종
        │
    크웰라 / 타운쉽 재즈 / 음바쾅가 / 음부베 / 이스카타미야로 분화
        (이스카타미야는 아카펠라 합창 — 레이디스미스 블랙 맘바조가 대표)
        │
    콰이토(Kwaito, 1990s) — 미국 하우스의 4/4 박자를 느리게 변형 + 토속 리듬 접목.
        아파르트헤이트 종식 직후 흑인 청년문화의 상징
        │
        └─ 아마피아노(Amapiano, 2012~) — 줄루어 '아마'(복수형 관사) + '피아노'.
                콰이토 기반 + 딥하우스·재즈·로그 드럼 베이스라인. 2020년대 세계적으로 확산

5. 북아프리카: 라이(Raï)

알제리 오랑 지역에서 발전. 아랍-베르베르 음악 전통 + 프랑스 식민 지배기의 카바레·샹송 영향 + 이후 록/신스 편곡. 사하라 이남 아프리카와는 계보적으로 독립적이며, 지중해·중동 음악권에 더 가까움.

6. 교차 요약

  1. 콩고 룸바의 순환 구조 — 아프리카 리듬이 노예제를 통해 쿠바로, 다시 라디오를 통해 콩고로 돌아오는 왕복 여정
  2. 아프로비트의 이중 뿌리 — 하이라이프(자국 전통)와 제임스 브라운식 훵크(미국 역수입)의 결합
  3. '아프로비트'와 '아프로비츠'는 다른 개념 — 전자는 1970년대 정치적 장르, 후자는 2010년대 이후 포괄적 상업 사운드
  4. 남아공의 자기완결적 계보 — 마라비에서 아마피아노까지 거의 전적으로 타운쉽 내부의 혼종화로 이어지는 독특하게 폐쇄적인 발전 경로

참고 자료

  • 위키백과 「아프로비트」, 「아프로비츠」 항목
  • 성기완, 「아프로, 끊임없이 태어나는 아프리카의 음악」, 서울대 아시아연구소 DiverseAsia
  • 실용음악 위키, 「남아공 음악」, 「대표적인 남아공 음악 장르」 항목
  • 나무위키 「아마피아노」 항목

서아프리카·남아공 갈래는 미국 계보의 블루스·훵크·하우스와, 콩고·세네갈 갈래는 유럽 계보의 프렌치 팝과 이미 여러 지점에서 교차함.

PLATE V

라틴아메리카

라틴아메리카 음악

0. 뿌리: 삼중 융합 — 유럽·원주민·아프리카

라틴아메리카 음악은 어느 한 갈래로도 환원되지 않는 세 원천의 혼합임. 스페인·포르투갈 식민 음악(기타, 코드 진행, 발라드 형식), 원주민(인디오) 음악(케나·차랑고 등 안데스 고유 악기, 펜타토닉 선율), 아프리카 노예 음악(타악기, 폴리리듬, 콜 앤 리스폰스)이 지역별로 다른 비율로 섞이며 나라마다 다른 정체성의 장르를 낳았음. 카리브해·브라질 연안은 아프리카적 요소가, 안데스 산악지대는 원주민적 요소가 더 강함.

1. 쿠바: 손 → 룸바 → 맘보 → 살사

클라베(2-3 혹은 3-2 리듬 패턴) 하나가 이후 거의 모든 갈래를 관통함.

손(Son, 19세기 말~) — 스페인 기타·가사 전통 + 아프리카 타악(봉고·클라베)
        │
룸바(Rumba, 아프리카계 노동자 공동체) — 순수 타악 + 콜 앤 리스폰스
        │
맘보(Mambo, 1930~40s) → 차차차(1950s) — 손 오케스트라의 빅밴드화, 이후 리듬 단순화
        │
        └─ 살사(Salsa, 1960~70s, 뉴욕) — 쿠바·푸에르토리코 이주민이 뉴욕에서
                손·맘보·재즈·R&B를 결합해 재정립. '살사'라는 이름 자체가 뉴욕에서 마케팅상 붙여짐

살사는 쿠바 음악이 미국 이민사를 거쳐 다시 라틴아메리카 전역으로 역수출된 사례로, 콩고 룸바의 순환 구조와 정확히 대칭을 이룸.

2. 브라질: 삼바 → 보사노바 → MPB / 카림보 → 람바다

삼바(Samba, 리우데자네이루, 1910s~) — 아프리카(반투족) 타악 전통 + 포르투갈 선율,
        카니발 문화와 결합
        │
        ├─ 보사노바(Bossa Nova, 1950~60s) — 삼바 리듬의 절제된 재해석 + 미국 쿨재즈 화성
        │       (안토니우 카를루스 조빙, 주앙 지우베르투)
        └─ MPB(Música Popular Brasileira, 1960s 말~) — 록·포크 요소를 흡수한 포괄적 명칭

포호(Forró, 브라질 북동부) — 삼바·보사노바 계보와 별개, 아코디언 중심 지역 댄스음악

카림보(Carimbó, 벨렝, 포르투갈 식민지 시대~) — 브라질 북부 고유 리듬, 카리브해와 상호 영향
        │
        └─ 람바다(Lambada, 1980년대) — 카림보 + 카리브해 메렝게가 벨렝 라디오를 통해 결합.
                1989년 프랑스 밴드 카오마의 동명 히트곡으로 세계적 유행(단, 원곡은 볼리비아
                포크 밴드 로스 캬르카스의 〈Llorando se fue〉(1981) 무단 편곡 논란 있음)
                └─ 2000년대 이후 브라질리언 주크로 계승

3. 아르헨티나·우루과이: 탱고

부에노스아이레스·몬테비데오 항구 이민자 사회에서 발생. 아프리카계 후손의 칸돔베(Candombe) 리듬, 스페인·이탈리아 이민자의 유럽 춤곡, 쿠바 하바네라 리듬이 뒤섞여 탄생했다는 것이 정설. 반도네온이 핵심 음색, 20세기 초 파리 소개를 계기로 세계적 명성을 얻음.

4. 카리브해: 레게 → 레게톤 / 메렝게·바차타

자메이카 레게 — 스카·록스테디를 거쳐 확립, 라틴아메리카 전역에 리듬적 영향
        │
        └─ 레게톤(Reggaetón, 1990년대 말, 푸에르토리코) — 자메이카 댄스홀 + 힙합 +
                살사·봄바 리듬, '덴보우(dembow)' 리듬이 핵심. 다디 얀키·돈 오마르가 대중화,
                2010년대 이후 세계 팝 표준 리듬으로 확산(〈Despacito〉가 상징적 계기)

메렝게(Merengue) / 바차타(Bachata) — 도미니카공화국. 메렝게는 빠른 2박, 바차타는
        기타 중심의 느린 서정적 리듬. 레게톤과 별개로 독자 계보 유지

5. 멕시코: 마리아치 → 노르테뇨·반다 → (나르코)코리도

마리아치는 스페인 현악 편성이 강한 갈래. 노르테뇨·반다는 19세기 독일계 이민자의 아코디언·브라스밴드 영향을 받아 멕시코 북부에서 발전. 코리도는 서사적 발라드 형식으로, 2010년대 이후 마약 카르텔 소재를 다루는 나르코코리도로 논쟁적 주목을 받음.

6. 안데스: 원주민 음악 → 누에바 칸시온

케나(팬플루트)·차랑고 등 잉카 이전부터의 원주민 악기 전통이 1960~70년대 누에바 칸시온(Nueva Canción) 운동을 통해 정치적 포크음악으로 재해석되었음. 빅토르 하라(칠레)가 대표적이며, 남미 좌파 정치운동과 밀접히 결합된 갈래임.

7. 교차 요약

  1. 클라베 리듬의 편재성 — 손·룸바·맘보·살사·탱고의 하바네라 리듬까지, 쿠바발 리듬 패턴이 라틴아메리카 댄스음악 전체의 공통 문법
  2. 살사의 뉴욕 이주사 — 콩고 룸바처럼, 쿠바 음악이 미국 이민 공동체를 거쳐 재정의된 뒤 본토로 역수출된 구조
  3. 레게톤의 혼종성 — 자메이카(레게)·미국(힙합)·쿠바/푸에르토리코(살사·봄바)가 겹겹이 섞인 21세기 표준 리듬
  4. 삼중 융합 비율의 지역차 — 카리브해·브라질(아프리카 요소 강함) vs 안데스(원주민 요소 강함) vs 아르헨티나(유럽 이민 요소 강함)
